# Кластерный анализ Leaf Dataset

Проект по кластерному анализу изображений листьев растений на основе их характеристик.

В рамках проекта реализован метод **максимально удалённых эталонов**, выполнен подбор количества кластеров, оценка качества разбиения и визуализация результатов с помощью PCA и t-SNE.

## 1. Постановка задачи

Цель проекта — разделить экземпляры листьев на однородные группы без использования информации об исходных классах растений.
Объекты внутри одного кластера должны быть похожи по форме и текстуре листа, а объекты из разных кластеров - отличаться.
Для исследования использован **Leaf Dataset**, содержащий 340 экземпляров листьев растений.
Исходный датасет представлен в файле:
./data/leaf.csv`
В исходных данных содержится 16 столбцов:
- класс растения;
- номер образца;
- 14 количественных признаков.
Класс растения и номер образца не использовались при кластеризации, поэтому итоговая матрица «объект–признак» имеет размерность: `340 × 14`

## 2. Признаки

Для кластеризации использовались морфологические признаки формы листа:
- эксцентриситет;
- отношение сторон;
- вытянутость;
- плотность формы;
- стохастическая выпуклость;
- изопериметрический фактор;
- максимальная глубина вырезов;
- лопастность.
Также использовались текстурные признаки изображения:
- средняя интенсивность;
- средний контраст;
- гладкость;
- третий момент;
- однородность;
- энтропия.
Перед кластеризацией признаки были стандартизированы с помощью `StandardScaler`.

## 3. Мера расстояния

Для оценки сходства объектов использовалось **косинусное расстояние**.
Косинусное сходство определяется как:
\[
\cos(x, y) =
\frac{x \cdot y}
{\|x\| \|y\|}
\]
Косинусное расстояние:
\[
d(x, y) = 1 - \cos(x, y)
\]
На основании стандартизированных признаков была сформирована матрица «объект–объект» размерностью: `340 × 340`

## 4. Метод кластеризации

Для кластеризации реализован **метод максимально удалённых эталонов**.
Алгоритм работает следующим образом:
1. случайным образом выбирается первый эталон;
2. для каждого объекта определяется расстояние до ближайшего уже выбранного эталона;
3. следующим эталоном становится объект, максимально удалённый от существующих эталонов;
4. процесс продолжается до получения необходимого количества эталонов;
5. каждый объект относится к кластеру ближайшего эталона.
Центры кластеров не рассчитываются как средние значения объектов, а выбираются непосредственно из исходной выборки.

## 5. Выбор количества кластеров

Количество кластеров исследовалось в диапазоне: `k = 2 ... 10`
Для оценки разбиений использовались:
- Silhouette Score;
- Calinski–Harabasz Index;
- Davies–Bouldin Index;
- внутрикластерная сумма квадратов (SSE);
- метод локтя.
По результате было выбрано: `k = 3`

## 6. Результаты кластеризации

При `k = 3` получены кластеры следующих размеров:

| Кластер | Количество объектов |
|---|---:|
| 0 | 110 |
| 1 | 103 |
| 2 | 127 |

Оценки качества итогового разбиения:

| Метрика | Значение |
|---|---:|
| Silhouette Score (cosine) | 0.475 |
| Calinski–Harabasz | 126.16 |
| Davies–Bouldin | 1.305 |

Полученное значение Silhouette Score показывает наличие кластерной структуры, хотя между отдельными группами сохраняется частичное пересечение.

## 7. Визуализация

Для визуального анализа многомерных данных использовались методы снижения размерности:

### PCA

Метод главных компонент использован для проекции объектов из 14-мерного пространства признаков в двумерное пространство.

### t-SNE

t-SNE использован как дополнительный нелинейный способ визуализации локальной структуры данных.

Обе визуализации позволяют оценить расположение объектов и взаимное пересечение полученных кластеров.

Все графики и расчёты представлены в: ./notebooks/leaf_clustering.ipynb`

## 8. Интерпретация кластеров

Для интерпретации были рассчитаны средние значения признаков внутри каждого кластера и их отклонения от средних значений по всей выборке.

### Кластер 0

Характеризуется относительно компактной формой листа и повышенными значениями текстурных характеристик:

- средней интенсивности;
- контраста;
- гладкости;
- третьего момента;
- энтропии.

### Кластер 1

Наиболее выраженными характеристиками являются:

- высокая вытянутость;
- большое отношение сторон;
- повышенная глубина вырезов;
- высокая лопастность;
- более сложная форма контура.

Кластер можно охарактеризовать как группу преимущественно вытянутых листьев со сложной формой.

### Кластер 2

Характеризуется:

- меньшей вытянутостью;
- высокой плотностью формы;
- высоким изопериметрическим фактором;
- меньшей глубиной вырезов и лопастностью.

Кластер соответствует более компактным и близким к округлым формам листьев.
